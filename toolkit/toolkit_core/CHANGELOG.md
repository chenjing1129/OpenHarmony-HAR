## 版本说明

### 版本号规则

本项目遵循语义化版本规范：`主版本号.次版本号.修订号`

- **主版本号**：进行不兼容的 API 更改时递增
- **次版本号**：以向后兼容的方式添加功能时递增
- **修订号**：进行向后兼容的错误修复时递增

### 变更类型说明

- `新增` - 新功能或新特性
- `变更` - 现有功能的变更
- `废弃` - 即将删除的功能
- `移除` - 已删除的功能
- `修复` - 错误修复
- `安全` - 安全性相关的修复
- `优化` - 性能优化
- `文档` - 文档更新
- `配置` - 配置文件或项目设置的变更
